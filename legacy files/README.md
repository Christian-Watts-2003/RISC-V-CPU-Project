# Legacy files

This directory contains superseded RTL and simulation sources retained for
reference only. Do not add these files to the active Vivado simulation or
synthesis source set.

- `rtl-root/` contains the former root-level RTL copies.
- `single_cycle_reference/` contains the archived single-cycle reference.
- `sim/` contains older testbenches for those sources.

The maintained single-cycle implementation is under `rtl/single_cycle/`.
The pipeline implementation is under `rtl/pipeline/`.
